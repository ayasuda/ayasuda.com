最近、AI に AWS CLI を叩かせている。

僕が指示すると、AI が AWS の環境を調べたり、設定を変更したりしてくれる。便利なものだ。

ところで、これ、僕の権限で動いている。

つまり、僕が AWS でできることは、AI にもできるわけだ。

まあ、僕が指示しているんだから、それでいい気もする。

しかし、そろそろインフラ運用も自動化したい。

例えば1日に1回、AWS のメトリクスを確認して、改善案を提案してほしい。イベントフックで定期的に動かして、何か問題があれば教えてくれる。

いいじゃないか。

さらに言えば、改善案を出すだけじゃなくて、修正して、デプロイして、ログを確認して、安全かどうかまで判断してほしい。

……あれ？

これ、僕の権限でやるの？

いやいや。AI 用のサービスアカウントを作って、専用の IAM Role を渡すべきだろう。

で、どこまで渡すんだ？

## AI にどこまで任せるか

ちょっと整理してみた。

| AI に任せること | 権限の渡し方 |
|---|---|
| メトリクス・ログの確認 | 読み取り専用ならよさそう |
| 改善案の提案 | 自動でやってほしい |
| コードの修正 | もう任せている |
| テスト環境へのデプロイ | 限定的な権限ならよさそう |
| 本番環境へのデプロイ | できれば任せたいが、ちょっと怖い |
| IAM Role の変更 | かなり怖い |
| DB の削除 | やめてほしい |
| 自分自身の権限変更 | それは困る |

こんな感じだろうか。

本番環境へのデプロイくらいは、いずれ自動でやってほしい。デプロイしたあと、しばらくログを見て、問題があれば対応してくれる。

そこまでできれば、僕が夜中に起きて対応する必要もなくなるかもしれない。

でも、怖い。

「今月の AWS の請求額です！」

とんでもない金額が表示される。

あるいは、

「あ。ごめんなさい。マスター DB を消しました」

いや、そんなことにはならないと思う。

思うけど……。

## そういえば IAM も AI に任せたい

そもそも IAM Role の設定って難しいじゃないか。

どのサービスにどんな権限が必要で、どのリソースに対して何を許可するのか。

あれを考えるのも、設定するのも、面倒だ。

だったら、AI にやってもらえばいい。

「田中さんに権限をつけて」

これで AI が適切な IAM Policy を考えて、設定して、適用してくれたら最高だ。

……あれ？

その AI には、IAM を変更する権限が必要だ。

つまり、AI に権限を設定してもらうために、AI に権限を変更する権限を渡す。

それって大丈夫なのか？

いや、適切に制限すればいいんだろうけど、その制限を考えるのも、できれば AI に任せたい。

困ったな。

## 人間には肩書がある

人間だったら、どうするんだろう。

例えば、田中さんがインフラ担当者なら、IAM を変更する権限を渡すこともあるだろう。

人間の場合、信頼は肩書ベースだ。

もちろん、肩書があれば何でも許されるわけではないが、少なくとも組織の中で役割が決まっていて、その役割に応じて権限を渡すことができる。

でも、AI はどうなんだ？

AI にインフラ管理者という肩書をつければいいのか？

そもそも、AI が人間よりうまく IAM Policy を設定できる可能性だってある。

だから任せたい。

でも、やっぱり怖い。

結局、僕がどこまで責任を負えるのか、という話になるのかもしれない。

とはいえ、どこまでなら大丈夫なのかがわからない。

いや、本当にどうすりゃいいんだろう。

## 去年も同じようなことで悩んでいた

なんだか、去年も同じようなことで悩んでいた気がする。

「AI にどこまでコードを任せていいんだっけ？」

2025年11月頃を思い返してみると、だいたいこんなことで悩んでいたんじゃないだろうか。

| AI に任せること | 自動化の範囲 |
|---|---|
| コードの調査・解析 | 自由にやってよい |
| 実装方針の提案 | 自動でやってほしい |
| コードの生成・修正 | 任せたいが、差分は確認したい |
| テストコードの作成 | 任せてもよさそう |
| テストの実行 | 自動でやってよい |
| リファクタリング | 既存の動作を壊さないか心配 |
| Git のコミット | 勝手にやってよいのか悩む |
| Pull Request の作成 | ここまでは自動化できそう |
| Pull Request のマージ | 人間がレビューしてから |
| 本番へのデプロイ | さすがに人間が判断するべきでは？ |

あの頃は、AI にコードを書かせて、それを人間がレビューして、どこまで信用していいのか考えていた。

ところが、今の僕はダークファクトリーだ。

コードを書くことについては、もうかなり AI に任せている。

去年はあんなに悩んでいたのに。

そう考えると、来年の僕は、IAM Role のことでも悩まなくなっているのかもしれない。

AI に権限を渡して、勝手にインフラを運用してもらっているかもしれない。

……いや、マジで？

皆さん、AI にどこまで IAM Role を渡している？
